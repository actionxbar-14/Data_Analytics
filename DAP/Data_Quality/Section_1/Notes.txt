
-------------------------------
:: What is Data Quality :
-------------------------------

--> Data Quality refers to the overall health of your data, it incompasis features like :

1. Accuracy [ Is the data free from error and typos ? ]
2. Consistency [ Is the data formatted uniformly throughout ? ]
3. Completeness [ Does the data have all the necessary information ? ]
4. Timeliness [ Is the data up-to-date & reflects the current state ? ]

-------------------------------
:: Data Profiling & Analysis :
-------------------------------

- Conduct in-depth analysis of data to identify patterns , anomalies , potential quality issues. 
- Access data characteristics - data types , missing values , outliers &  inconsistencies. 
- Employ data analysis , visualizations techniques to identify data quality issues. 




_________________________________________________________________________________________________________________________________________________


-------------------------------------
:: Data Validation & Verification :
-------------------------------------

- Define and enforce data validation rules to ensure data accuracy & consistency. 
- Cross-referencne data with other sources to verify accuracy. 
- Perform manual reviews and use automated validation tools. 





__________________________________________________________________________________________________________________________________________________





-------------------------------------
:: Root Cause Analysis :
-------------------------------------

- Investigate the root causes of data quality problems & recommend solutions. 
- Ex : if data inconsistencies appear , they investigate whether it's due to system issues , user error , or integration problems to work on targeted fixes. 





__________________________________________________________________________________________________________________________________________________



-------------------------------------
:: Data Cleansing & Standardization :
-------------------------------------

- Correct errors , remove duplicates and handle missing values. 
- Standardize data formats , normalize data and apply consistent naming conventions. 
- Implement data cleansing and standardization processses to improve data quality. 

## NOTE : 
- It is optional and depends on Organization data architecture standards. 




__________________________________________________________________________________________________________________________________________________




--------------------------------------------
:: Data Quality Monitoring and Reporting :
--------------------------------------------

- Establish metrics / KPIs( Key Performance Indicators ) to measure data quality. 
- Set up automated monitoring systems to track data quality metrics. 
- Generate regular reports on data quality metrics & trends. 




__________________________________________________________________________________________________________________________________________________





--------------------------------------------
:: Business Stakeholder Engagement :
--------------------------------------------

- Work closely with business stakeholders to understand their data needs. 
- Communicate data quality insights to stakeholders.

## NOTE :

--------------------------------------------
:: 7-Most common data quality issues :
--------------------------------------------

1. Duplicate Data. 
2. Inaccurate Data. 
3. Ambiguous Data. 
4. Hidden Data. 
5. Inconsistent Data. 
6. Stale Data. 
7. Orphaned Data. 



--------------------------------------------------------------------------------------------------------------------------------------------------



1.) Duplicate Data : 
- Duplicate data can be occured in the system when , there is Data Silos( data present in multiple systme )  , Human error and Inconsistent Data Entry. 


2.) Inaccurate Data :
- Inaccurate Data is the data which is not relevant and not upto date for the analysis and consist many errors. 


3.) Ambiguous Data :
- Ambiguous Data is the data which Contain Missing Context(relevant information) , abbreviation( CA -> california , CA -> Charted Accountant ) , inconsistent formatting( date format written in String format ).


4.) Hidden Data :
- Data Silos , Embedded Files ( documents , pdf ) , Legacy Systems( old data system ) , Lack of documentation.


5.) Inconsistent Data :
- Same data present in different format( Ex : Customer Address [ '123 Main St.' , '123 Main Street' ]).
- Different Data entry formats ( Ex : Date [ YYYY-MM-DD , MM/DD/YYYY ]  , Measurments [ Mts , Ft] ).
- Missing Standards like ( Ex : State[ 'NY' , 'NewYork'] ).
- Manual data update ( Ex : data migration , Merging the large data into one system ). 
- Lack of Data validation. 




6.) Stale Data :
- Stale Data means the data is not static , information change over time such as ( Ex : Customer address , Phone number , product preferences ). 
- However data does not always get updated regularly , this can lead to stale data which is information that is no longer current. 
- Lack of Update processes , Data silos , Customer Churn Are the main reason. 



7.) Orphan Data:
- Orphaned Data occures due to the Deleted parent current records , Incomplete data migration , System changes.
- It can Waste storage space , Clutter databases ,  difficult to get a complete picture of the information.
