## MEASURES IN POWER BI :-

- Measures are calculations used in Power BI to perform aggregations and calculations on data. They are created using DAX (Data Analysis Expressions) and can be used in visuals, reports, and dashboards.
- It has two types :



1.Implicit Measures :
- Implicit measures are automatically created by Power BI when you drag a numeric field into the Values/visual charts.



2.Explicit Measures :
- Explicit measures are created by the user using DAX formulas and can be reused across multiple visuals and reports.




==================================================================================================================================================



## Calculated Columns in Power BI :- 

- A Calculated Column is a new column that you create in a table using DAX ( Data Analysis Expressions ). The Value for each row is calculated when the column is created , and it remains static unless the data is refreshed. 

- Example :

Tax = SalesData[Total_Sales] * 18/100. 


--> Use Case : 
- Suitable for scenarios where you need a value for each row in the table , such as adding a new field derived from existing data(e.g., creating a "Total Price" column by multiplying "Quantity" and "Price"). 


--> Performance : 
- Since calculated columns are stored in the model , they can affect performance , especially if the model is large. 





==================================================================================================================================================




## Difference Between Calculated Columns and Measures :-


1. Calculation Timing : 

--> Calculated Column :- Calculated when tha data is loaded or refreshed. 
--> Measure :- Calculated dynamically during reporting. 


2. Storage : 

--> Calculated Column :- Stored in the data model as a new column.
--> Measure :- Not stored in the data model ; calculated on-the-fly. 


3. Context : 

--> Calculated Column :- Row context ( Calculation per row ). 
--> Measure :- Filter / context-dependeent ( Changes dynamically ). 



4. USE :

-->  Calculated Column :- Adding new fields for each row. 
-->  Measure :- Aggregating or summarizing data. 



5. Performance Impact : 

-->  Calculated Column :- Can increase model size and memory usage.
-->  Measure :-  Impacts report performance, not model size.

1. SUM Formula in DAX :- 

- SUM is a simple aggregation function that adds up all the values in a single column. 

- Syntax : SUM(<column>)

--> Example  : 

Total Sales = SUM(SalesData[Sales])   [ Where SalesData is the table name and Sales is the column name ]


--> Use Case :
- Use SUM When you want to sum up all the values in a numeric column Without any complex row-by-row operations. 

--> Performance :
- Since it operates directly on a column , it's fast and efficient for simple summations. 




__________________________________________________________________________________________________________________________________________


2. SUMX Formula : 

- SUMX is an iterator function that performs row-by-row calculations and then sums the results. 

- Syntax : SUMX(<table>, <expression>)

- Example : 
 
Total_Sales_2 =  SUMX(SalesData , SalesData[Quantity] * SalesData[Unit Price ( INR ) ])


--> Use Case : Use SUMX when you need to perform a calculation for each row before summing , such as multiplying two columns together or applying conditional logic. 

--> Performance : SUMX can be slower than SUM because it performs calculations on each row individually before summing. It's ideal for more complex scenarios that require row context. 



__________________________________________________________________________________________________________________________________________






## Difference Between SUM and SUMX : 


- In PowerBI , both SUM and SUMX are used to perform summation , but they work differently and are used in different scenarios. Here's a breakdown of the key differences : 

1. Function Type :-

-->  SUM  : Aggregation Function. 
-->  SUMX : Iterator function. 



2. Operation :-

--> SUM  : Sums all values in a single column directly. 
--> SUMX : Calculates row by row based on an expression , then sums. 


3. Input :- 

--> SUM  : Single Column.
--> SUMX : Table and an expression. 



4. Use Case :- 

--> SUM  : Simple Summation of a numeric column. 
--> SUMX : When you need to calculate something for each row before summing. 



5. Performance :- 

--> SUM  : Fast and efficient. 
--> SUMX : Slower for large datasets  , as it iterates over rows.

3. COUNT Formula :

- COUNT counts the number of 'non-blank' values in a column. 
- Syntax : COUNT(<column>)



- Ex :  Number of Customers = COUNT('Table'[Customer ID])


## Use Case : When you want to count the non-empty values in a column. 




__________________________________________________________________________________________________________________________________________



4. COUNTA Formula : 

- COUNTA counts the number of non-blank values in a column , including text , numeric values and logical values even counts "Boolean values" where only Count will not count Boolean data type. 
- Syntax : COUNTA(<column>)



- Ex : Number of Reviews  = COUNTA('Table'[Review Status])



## Use Case : 
- When you need to count all non-blank values , regardless of the data type (text , numbers , etc). 





__________________________________________________________________________________________________________________________________________




5. COUNTBLANK Formula : 

- COUNTBLANK counts the number of blank(empty) values in a column. 
- Syntax : COUNTBLANK(<column>)



- Ex :  Blank Reviews = COUNTBLANK('Table'[Review Points])


## Use Case : When you want to count the number of blank or missing values in a column. 




__________________________________________________________________________________________________________________________________________



6. COUNTROWS Formula : 

- COUNTROWS counts the number of rows in a table.
- Syntax : COUNTROWS(Table_name)



- Ex :  Total Records = COUNTROWS('Table')


## [ COUNTROWS with Filter ]

- Ex :  Total Records Filter = COUNTROWS(FILTER('Table' , 'Table'[State] = "Maharashtra"))


## Use Case :  When you want to count the total number of rows in a table or in a filtered table. 



__________________________________________________________________________________________________________________________________________


7. DISTINCTCOUNT : 

- DISTINCTCOUNT counts the number of unique , non-blank values in a column. 
- Syntax : DISTINCT(<column>)



- Ex :  Unique States = DISTINCTCOUNT('Table'[State])



## Use Case : When you need to count the distinct (Unique) values in a column , excluding blanks. 


__________________________________________________________________________________________________________________________________________



8. COUNTX Formula : 

- COUNTX is an iterator function that counts non-blank results of an expression evaluated row by row over a table. 
- Syntax : COUNTX(Table_name , Expressions(for ex : IF , ..))


- Ex : CountX = COUNTX('Table' , IF('Table'[Review Points] >= 7 , 1 , BLANK()) )




## [ COUNTX with FILTER ]

- Ex : CountXFilter = COUNTX(FILTER('Table' , 'Table'[State] = "Maharashtra") , 'Table'[State])


## Use Case : When you need to count based on an expression that is evaluated for each row in a table. 


__________________________________________________________________________________________________________________________________________



9. COUNTAX Formula : 

- COUNTAX is the iterator version of COUNTA. It evalutes and expression for each row and counts the number of non-blanks results. 
- Syntax : COUNTAX(Table_name , Expressions(for ex : IF , ..))


- Ex :  CountAX = COUNTAX('Table' , IF('Table'[Review Status]=TRUE, 1 , BLANK()) )



## [ COUNTAX with Filter ]

- Ex : CountAXFilter = COUNTAX(FILTER('Table' , 'Table'[Review Status] = FALSE()) , 'Table'[Review Status])


## Use Case :  When you need to count based on an expression that is evaluated for each row in a table even there is Binary data type.

10. DATE & TIME Functions : 


- DAY(<datetime>)    : Extracts the day from a date value.

- MONTH(<datetime>)  : Extracts the month from a date value.

- YEAR(<datetime>)   : Extracts the year from a date value.

- HOUR(<datetime>)   : Extracts the Hour from a date and time value.

- MINUTE(<datetime>) : Extracts the Minute from a date and time value.

- SECOND(<datetime>) : Extracts the Second from a date and time value.

- Today()            : Show Current date.

- Now()              : Show current date and Time.
 
- Weekday()          : Show Weekday in numbers between 1 to 7.

- Weeknum()          : Show Week number in Month/Year.

- FORMAT             : Formats a value as text according to a specified format. ( Ex : FORMAT(SalesData[Date].[Date] , "DDD")  )

- Syntax : DATEDIFF(<start_date>, <end_date>, <interval>)

- Example :  DATEDIFF(Sales[OrderDate], Sales[ShipDate], DAY)

13. MTD / QTD / YTD Functions : 



i).  MTD (Month-To-Date)    : 
- Calculates the total from the beginning of the current month up to the current date.
- Ex :  MTD = TOTALMTD([Total_Sales] , Custom_Calender[Date])





ii). QTD (Quarter-To-Date) : 
- Calculates the total from the beginning of the current quarter up to the current date.
- Ex :  QTD = TOTALQTD([Total_Sales] , Custom_Calender[Date])





iii). YTD (Year-To-Date)   : 
- Calculates the total from the beginning of the current year up to the current date.
- Ex :  YTD = TOTALYTD([Total_Sales] , Custom_Calender[Date])

15.  DATESINPERIOD Function : 

- The DATESINPERIOD function returns a table that contains a column of dates that begins with a specified start date and continues for a specified number of intervals (days, months, quarters, or years). It is useful for creating dynamic date ranges in time intelligence calculations.
- Syntax : 
DATESINPERIOD(<dates>, <start_date>, <number_of_intervals>, <interval>)

- Ex :

Sep2023DatesINPeriod = CALCULATE([Total_Sales] , DATESINPERIOD(Custom_Calender[Date],
"24-09-2023" ,7, DAY))




__________________________________________________________________________________________________________________________________________


16. DATESBETWEEN Function :

- The DATESBETWEEN function returns a table that contains a column of dates that fall between two specified dates. It is useful for filtering data within a specific date range.
- Syntax : DATESBETWEEN(<dates>, <start_date>, <end_date>)

- Ex :
Sep2023DatesBETWEEN = CALCULATE([Total_Sales] , DATESBETWEEN(Custom_Calender[Date] , 
 "24-09-2023" , "30-09-2023"))

18. TEXT Formulas :



## FIND(<find_text>, <within_text>, [<start_num>]) :
- Returns the starting position of one text string within another text string. The search is case-sensitive
- Ex: 

FName = LEFT(SalesData[Customer Name] , FIND(" " , SalesData[Customer Name] , 1)-1)








## LEFT(<text>, <num_chars>) /  RIGHTT(<text>, <num_chars>) :
- Returns the first/last character(s) in a text string based on the number of characters specified.
- Ex :

FName_LEFT = LEFT(SalesData[Customer Name] , FIND(" " , SalesData[Customer Name] , 1)-1)

FName_RIGHT = RIGHT(SalesData[Customer Name] , LEN(SalesData[Customer Name]) - FIND(" " , SalesData[Customer Name] , 1)) 





## UPPER / LOWER : 


- Ex :

Name_UPPER = UPPER(SalesData[Customer Name])
Name_LOWER = LOWER(SalesData[Customer Name])




## MID : 

- Ex : MID(SalesData[Customer Name] , 7 , 5) 




## LEN : 

- Ex:  LEN(SalesData[Customer Name])
