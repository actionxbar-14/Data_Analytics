


:: Power Query : 

- ETL tool.
- Power Query is the data preparation and ETL engine in PowerBI used to connect , clean and transform data before analysis.



:--> Power Query Pipeline : 


1. Connect    ---->    2. Remove Bad Data    ---->  3. Split   ---->  4. Merge   ---->  5. Remoe spaces.
[ NOTE :  order is important ]






--------------------------------------------------------------------------------------------------------------------------------------------------


:: Execution  :

--> Go to Home tab and then transform section and click transform data and then perform these in the loop :

-  [ Check -----> Inspect -------> Fix ]





--------------------------------------------------------------------------------------------------------------------------------------------------


:: Process Steps : 




## STEP_1 : [ Connect Data ]

-- Connect Sources.
-- Check Promoted headers. !
-- Change Types.

:-> It is Automatically done by the PowerBI.














## STEP_2 : [ Filter Data ]

-- Remove Unnecessary Columns.
-- Remove Blank Rows.
-- Filter Rows. 














## STEP_3 : [ Clean Data ]


1.)  Remove Duplicates : 
- A record that appears more than once with identical values.
- Primary key should unique.
   -> Text    :  Trim , Case , Replace.
   -> Numbers :  Format , Round , Type.
   -> Dates   :  Format  , Type.




2.)  Handle Missing Values / Data:
- [ null  --> unknown  , missing , Nothing ] = > Use Replace ( n/a ).
- [ Empty String --> ]Text Type  , But no value ] [ Length = 0]   => Use Trim.
- [ White spaces --> Text Type with Space value] [ Length = 1 ,2,.....]  => Use Replace ( null , n/a ).
- [ Numbers -->   null / 0 / avg].
- [ Dates -->  null / default value (31-12-9999) ].



















## STEP_4 : [ Transform Data ]


- Split Columns.
- Merge Columns.
- Extract Parts.





















## STEP_5 : [ Combine Data ]




i) Connect Using Relations :

- By Creating Data Model.




ii) Combine :

- Append Table. [ Union ]. ( Combining Rows ) 

- Merge Table [ Join ].  ( Combining Columns )
















## STEP_6 : [ Clean Data ]


- Remove Unnecessary Columns.
- Rename Tables & Columns "Naming Convenstions".
- Reorder the columns in logical order.

:: Bonus [ Reshape Data ] :

- Changing the layout of the table without changing the meaning and the values of your data inside the table.

## Two Methods :-



1. Pivot :
- [ PowerBI Friendly shape   TO  PowerBI - Friendly Shape ].
- [ Rows To Columns ].

- Go to transform tab under power query and select pivot columns option ( select that column which you want to unpivot ).





2. Un-Pivot : 
- [ Human - Friendly Shape  To  PowerBI - Friendly Shape ].
- [ Columns To Rows ].

- Go to transform tab under power query and select pivot columns option. ( Select pivot by value / default aggregate : sum).

:: Duplicate V/s Refrences Queries :




1. Duplicate :  [ Copying the Query ]

- Both have the same steps but are disconnected.
--> Dimension to Fact.
--> Disconnected to Original Query.





2. Reference : 

- Starts from the original query and inherits all applied steps.
