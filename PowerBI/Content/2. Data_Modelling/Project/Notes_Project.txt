:: Data Modelling Project : 



## STEPs :

1. Prepare & Explore : [ open the mess and understand the data ]

- Opens the messy model.
- Prepare the workspace.
- Understand the business. 
- Understand the data. 
- Spot dimensions v/s Facts.



2. Dimensions :  [ build them , and clean one by one ]

- Group the tables for one entity. 
- Reshape into one clean dimension. 
- Clean it to the standards. 
- Repeat for every dimension. 




3. Facts :  [ build , connect  , and test the numbers ]

- Pick an event  , read its grain. 
- Build the fact from the details. 
- Connect every dimension. 
- Test so the numbers never break. 



4. Polish : [ Secure it and validate the model ]

- Re-check the standards. 
- Add the data dimension. 
- Build the measures. 
- Add row-level security. 
- Final Validation. 












## Rules :


--> RULE_1 :  Build a Star Schema . [ a fact in the middle , dimensions around it ] :
--> RULE_2 :  Understand before you change. [ always read the grain first ] 
--> RULE_3 :  Protect the numbers [ Facts ]. [ know your totals , re-check after every change ]
--> RULE_4 :  Every column earns its place. [ If it does not help the report , drop it ]
--> RULE_5 :  Follow the Standards [ Language( English ), Naming( snake_case ) , Tables( fact and dim ) , keys( _key , _id ) , readable ]
